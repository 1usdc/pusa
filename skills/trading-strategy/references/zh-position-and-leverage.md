# 仓位与杠杆

仓位计算的核心不是“想赚多少”，而是“止损触发时最多亏多少”。实盘执行前必须区分保证金、名义价值和风险金额。

## 三个概念

- 风险金额：止损触发时计划承受的最大亏损。
- 名义价值：仓位对应的总交易价值。
- 保证金：开杠杆仓位时占用的本金。

这三者不能混用。用户说“开 500U”时，必须确认是 500U 名义价值、500U 保证金，还是最多亏 500U。

## 线性合约计算

```text
风险金额 = 账户权益 * 单笔风险比例
止损距离 = abs(入场价 - 止损价)
币本位数量 = 风险金额 / 止损距离
名义价值 = 币本位数量 * 入场价
保证金 = 名义价值 / 杠杆倍数
```

示例：

```text
账户权益 = 10,000 USDT
单笔风险 = 0.5%
风险金额 = 50 USDT
入场价 = 50,000
止损价 = 49,500
止损距离 = 500
数量 = 50 / 500 = 0.1 BTC
名义价值 = 0.1 * 50,000 = 5,000 USDT
10 倍杠杆保证金约 = 500 USDT
```

这笔交易占用约 500U 保证金，但计划风险是 50U。

## 杠杆检查

杠杆不是风险控制工具，只是改变保证金占用。高杠杆会缩短强平距离，增加滑点和穿仓风险。

执行前检查：

- 止损价是否明显早于强平价？
- 交易所合约面值和最小下单单位是否已确认？
- 手续费和资金费率是否会影响预期收益？
- 同方向相关仓位是否已经过多？
- 若价格跳空越过止损，账户能否承受？

## 需要澄清的表达

- “用 1000U 做多”：问是名义价值、保证金，还是最大亏损。
- “10 倍开 20% 仓”：问 20% 是权益、保证金还是名义价值。
- “买 5 张”：先查合约面值，再换算实际底层资产和 USDT 价值。
- “梭哈但带止损”：不接受，除非用户重新给出最大亏损和风险预算。
