# 风控优先交易框架

交易策略的第一原则是保本。任何策略在讨论收益之前，必须先说明最坏情况下会亏多少、什么时候认错、什么条件下暂停。

## 决策顺序

1. 先判断是否值得交易，而不是先决定买卖方向。
2. 先确定最大亏损，再计算仓位。
3. 先定义失效条件，再定义止盈目标。
4. 先验证市场状态，再选择策略类型。
5. 先模拟盘或小资金验证，再进入正常实盘仓位。

## 必须问清楚的问题

- 交易模式是实盘还是模拟盘？
- 交易所、币种、合约类型是否明确？
- 本次最多允许亏损多少？
- 止损价格或失效条件是什么？
- 仓位是按保证金、名义价值，还是账户风险来表达？
- 策略适合当前市场状态吗？
- 如果连续亏损，什么时候暂停？

## 不应执行的情况

- 用户只说“买入”“做多”“做空”，但没有仓位和止损。
- 用户要求高杠杆，但没有说明最大亏损和强平缓冲。
- 策略依赖“跌了就补”“亏了加倍”，但没有总预算和停止条件。
- 策略没有说明适用行情，例如趋势、震荡、突破或事件驱动。
- 数据不足，无法确认信号是否真实触发。

## 默认保守参数

如果用户没有指定风险参数，只能作为建议提出，不能擅自用于实盘：

- 单笔风险：账户权益的 0.25% 到 1%。
- 单日止损：账户权益的 2% 到 3%。
- 策略暂停线：从近期权益高点回撤 5% 到 8%。
- 连续亏损暂停：连续 3 到 5 笔亏损后停止自动执行，进入复盘。

## 输出格式

```text
结论：执行 / 不执行 / 需要回测 / 需要补充信息
理由：
最大风险：
止损或失效条件：
下一步：
```
