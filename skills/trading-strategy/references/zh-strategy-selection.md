# 策略选择

没有通吃所有行情的策略。先判断市场状态，再选择策略；市场状态不清楚时，优先空仓或降低频率。

## 市场状态

### 趋势行情

特征：

- 高低点同向抬升或下移。
- 回调较浅，突破后延续性较强。
- 均线斜率明显，价格多次沿均线运行。

适合：

- 趋势跟随。
- 突破追踪。
- 移动止损。

不适合：

- 逆势摸顶摸底。
- 无上限网格。
- 频繁均值回归。

### 震荡行情

特征：

- 价格在明确区间内反复来回。
- 突破失败较多。
- 成交量和波动率没有明显扩张。

适合：

- 区间网格。
- 均值回归。
- 支撑阻力反转。

不适合：

- 追突破。
- 过宽止损的趋势单。
- 高杠杆单边仓。

### 高波动事件行情

特征：

- 重大新闻、宏观数据、项目事件、清算瀑布。
- 点差扩大，滑点增加。
- K 线形态快速失效。

适合：

- 降低仓位。
- 等待波动回落。
- 只做明确计划内的事件策略。

不适合：

- 自动追单。
- 加倍补仓。
- 没有滑点保护的市价单。

## 策略选择表

```text
趋势明确 + 回撤有序 -> 趋势跟随
区间明确 + 波动稳定 -> 网格或均值回归
方向不明 + 波动收缩 -> 等待突破，不提前重仓
事件冲击 + 流动性变差 -> 降低仓位或暂停
连续亏损 + 信号失效 -> 停止策略并复盘
```

## 最小策略说明

每个策略至少包含：

- 适用行情。
- 入场条件。
- 出场条件。
- 止损或失效条件。
- 仓位计算方式。
- 暂停条件。
- 需要读取的数据。

缺少任意一项，都不能判断为可自动执行。
