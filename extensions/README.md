# extension/

存放**内部插件**的安装目录。

与 `skills/`（Agent 技能 Markdown 包）不同：本目录用于仓库内置、由产品自身加载的扩展能力（如内部工具、能力模块）。具体包格式与安装流程尚未定稿；在约定落地前，请勿在此放入占位插件。

## 约定（暂定）

- 每个插件一个子目录
- 不加入 Cargo workspace（与 `skills/` 同为内容目录）
- 安装与加载逻辑由应用侧后续接入

相关目录：

| 目录 | 用途 |
|------|------|
| `skills/` | Agent 技能（`SKILL.md`） |
| `extension/` | 内部插件 |
| `application/` | 外部应用 |
